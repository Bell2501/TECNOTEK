# TECNOTEK

Página web adaptable a móviles para presentar las soluciones de TECNOTEK en seguridad electrónica, computadoras, impresoras y consumibles.

## Abrir la página

Abre `index.html` en un navegador o configura GitHub Pages para publicar el sitio desde este repositorio.

El formulario prepara un mensaje en la aplicación de correo del visitante. Para recibir consultas en una dirección específica, reemplaza `mailto:` en el archivo `index.html` por el correo del negocio.
